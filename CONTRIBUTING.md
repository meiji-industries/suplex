# Contributing to Suplex

Suplex is source-available under the [Elastic License 2.0](LICENSE).

## Contributor License Agreement

Before we can merge your first pull request, you must accept the
[Suplex Contributor License Agreement](CLA.md). The CLA Assistant comments on
your pull request with the exact sentence to post. You accept the agreement
once, and it covers your later pull requests.

The agreement lets Meiji Heavy Industries, Inc. distribute your contribution
under the Elastic License 2.0 and under other license terms in the future. You
keep the copyright in your contribution.

## Before you open a pull request

Read [AGENTS.md](AGENTS.md) for where code goes and how to verify a change.
Do not add code that you cannot license to us, and name any third-party
license that applies to code you copy into the repository.
