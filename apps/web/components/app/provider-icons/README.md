Provider icons come from the Lobe Icons static SVG package.

Source: https://github.com/lobehub/lobe-icons/tree/master/packages/static-svg/icons

The adjacent `LICENSE` file contains the upstream MIT license.

`pi.svg` is a plain π glyph drawn for Suplex, because Lobe Icons has no Pi icon.
`omp.svg` is the same glyph in a square outline, drawn for Suplex for OMP.
