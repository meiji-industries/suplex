# Security policy

Report a vulnerability privately. Do not open a public issue.

- Use [GitHub private vulnerability reporting](https://github.com/meiji-industries/suplex/security/advisories/new), or
- Send an email to [support@getsuplex.ai](mailto:support@getsuplex.ai).

Include the affected version, the steps to reproduce the problem, and its impact.
Security fixes go into the latest release.
